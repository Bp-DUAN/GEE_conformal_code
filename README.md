# GEE_conformal_code
parametric FEMs for geometric evolution equations using conformal map

WConformal_Surface_CN_SEuler: To compute surface evolution of closed surfaces

WConformal_Surface_evolution_CN_SEuler: To compute the solid-dewetting model 

Main_Conv_test_time: To compute the convergence rates in time

conv_test_space: To compute convergence rates in space

functions: This file contains all needed functions 

mesh: This file contains all the mesh files needed
